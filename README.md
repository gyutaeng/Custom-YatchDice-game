# 캐릭터 만들기 가이드

요트다이스에 내 캐릭터를 등록하는 방법을 정리했습니다. 그림 그리는
프로그램이나 코딩 지식은 필요 없어요 - 이미지 파일과 목소리 파일만
준비하면 됩니다.

## 1. 스탠딩 이미지 (게임 화면에 크게 나오는 전신 그림)

- **권장 크기: 세로 1400px 이상** (긴 변 기준. 아래 "왜 이 크기인가" 참고)
- **비율: 세로로 긴 그림**. 사람이 서 있는 모습처럼 세로가 가로보다 훨씬
  긴 그림을 준비하세요.
- 화면에 표시될 때 **비율이 그대로 유지**되고 **잘리지 않습니다** -
  세로 기준으로 크기를 맞추고, 남는 공간은 그냥 여백으로 남습니다.
  (다만 아래 "썸네일" 항목에서 이 이미지가 다시 쓰일 때는 이야기가
  다릅니다 - 꼭 읽어보세요.)
- **아래쪽 정렬**이라 캐릭터의 발이 화면 맨 아래에 닿습니다. 그림을 그릴
  때 발밑에 여백을 많이 남기면 캐릭터가 화면에서 작아 보이니, 발을
  그림 맨 아래쪽에 붙여서 그리세요.
- **좌우 여백은 넉넉하게, 캐릭터는 가운데에.** 스탠딩 이미지는 나중에
  "썸네일(작은 초상)"이 따로 없을 때 정사각형으로 잘려서 대신 쓰입니다
  (2번 항목 참고) - 이때는 **이미지 맨 위에서, 가로 폭과 같은 높이만큼만**
  잘라서 보여줍니다. 즉 얼굴과 상반신이 "이미지 위쪽, 가로 폭 정도의
  높이" 안에 들어오게 그려두면 어떤 경우에도 안전합니다. 좌우는 이때도
  잘리지 않으니 가로 여백 걱정은 안 해도 됩니다.
- **배경은 투명하게** (PNG 또는 WebP 파일로 저장). 캐릭터 뒤에 네모난
  배경색이 그대로 보이면 안 어울립니다. **투명 배경이 필요하면 JPG는
  쓰지 마세요** - JPG는 투명을 지원하지 않는 파일 형식입니다.
- **한도: 긴 변 2048px, 파일 크기 4MB까지.** 이 이상은 업로드가
  거부됩니다.

### 왜 세로 1400px를 권장하나요?

이 게임은 화면 크기가 커지면 그림도 커집니다. 가장 큰 화면(2560×1440,
요즘 나오는 큰 모니터)에서 캐릭터가 표시되는 실제 크기를 재보니 세로
약 1174px였습니다. 그래서:

- **1174px보다 작으면**: 가장 큰 화면에서 그림이 살짝 흐릿하게 보일 수
  있습니다.
- **1400px 정도면**: 지금 나온 모든 화면 크기에서 선명하게 보입니다.
- **2048px(업로드 한도)까지 키워도**: 지금 화면 크기 기준으로는 더
  선명해 보이지 않고 파일 용량만 커집니다.

즉 **1400px 근처가 딱 적당한 크기**입니다. 화면이 훨씬 더 커지는 미래를
대비하고 싶다면 2048px까지 써도 괜찮지만, 보통은 그럴 필요가 없습니다.

### 비율(가로세로 비) - 크기 말고 이것도 중요합니다

크기(px)를 맞춰도 **비율이 안 맞으면 캐릭터가 작아 보입니다.** 이
그림은 잘라내지 않고 통째로 줄여서 넣는 방식이라(위에서 이미 설명한
"잘리지 않습니다"), 그림의 가로세로 비율이 화면이 마련해준 자리(슬롯)의
비율과 다르면 남는 공간이 그냥 빈 여백으로 남기 때문입니다.

- **권장 비율: 가로 3 : 세로 5** (예: 850×1400, 1200×2000처럼 세로가
  가로의 약 1.7배).
- 화면의 자리 자체는 인원수에 따라 살짝 달라지는데(가로 폭 기준
  358~441px, 세로는 항상 587px로 고정 - 1280×720 기준), **2~3인일 때가
  가장 좁습니다(약 3:5 비율).** 이 좁은 비율에 맞춰 그려두면 인원수가
  늘어나 자리가 조금 넓어져도(4인일 때 최대 441px) 옆에 여백이 살짝
  더 생길 뿐 캐릭터가 작아지지는 않습니다 - 그래서 **3:5 비율 하나로
  2~4인 전부 안전**합니다.

**더 길쭉한 그림은 괜찮고, 더 넓적한(정사각형에 가까운) 그림은
캐릭터가 작아 보입니다:**

```
[3:5 비율 - 딱 맞음]     [더 길쭉함 - 괜찮음]      [정사각형에 가까움 - 작아 보임]

+---------+             +---+-------+---+          +-------------+
|         |             |   |       |   |          |, , , , , , ,|  <- 빈 공간
|         |             |   |       |   |          +-------------+
|  캐릭터  |             |   | 캐릭터 |   |          |             |
|         |             |   |       |   |          |    캐릭터    |
|         |             |   |       |   |          |             |
+---------+             +---+-------+---+          +-------------+
                          ^ 좌우 여백(정상)            |, , , , , , ,|  <- 빈 공간
자리를 꽉 채움            세로는 꽉 채움, 정상          +-------------+
                                                    세로 공간 절반이 빈 여백
                                                    → 캐릭터가 왜소해 보임
```

정사각형이나 그에 가까운 그림을 올려도 **에러가 나거나 잘리지는
않습니다** - 다만 위 그림처럼 위아래에 여백이 크게 남아서 캐릭터가
화면에서 작고 초라해 보일 수 있습니다. 이게 실제로 제일 흔하게 나올 수
있는 실수라, 처음부터 세로로 넉넉히 긴 비율(3:5 정도)로 그려두는 걸
권장합니다.

## 2. 썸네일 (작은 초상 - 정사각형 얼굴 그림)


다른 플레이어의 차례일 때, 캐릭터를 고를 때, 게임이 끝났을 때 등
여러 화면에서 작게 표시되는 정사각형 그림입니다.

- **권장 크기: 256×256px, 정사각형(1:1 비율)**
- **얼굴이 가운데 오게** 그리세요. 정사각형이 아닌 그림을 올리면 가운데
  기준으로 남는 부분이 잘려서 보여집니다 - 처음부터 정사각형으로
  준비하면 잘리는 부분 없이 그대로 다 보입니다.
- **안 올려도 됩니다.** 썸네일을 따로 안 올리면 위에서 만든 스탠딩
  이미지의 **위쪽을 정사각형으로 잘라서** 자동으로 씁니다(1번 항목의
  "왜 세로 1400px를..." 바로 위 설명 참고). 캐릭터를 하나만 준비하고
  싶다면 스탠딩 이미지만 올려도 충분합니다.
- **한도: 긴 변 1024px, 파일 크기 1MB까지.**

가장 크게 표시되는 화면(캐릭터 선택 화면) 기준으로 계산해도 실제로
필요한 크기는 200px 안팎이라, 256px면 어떤 화면에서도 넉넉합니다 -
1024px까지 키울 필요는 없습니다.

## 3. 보이스 (캐릭터 목소리)

`여기 스크린샷 - 캐릭터 편집 화면의 보이스 매핑 목록`

캐릭터가 게임 중 특정 상황에서 낼 목소리(짧은 대사, 웃음소리, 감탄사
등)를 이벤트별로 등록할 수 있습니다. 아래 9가지 상황에 각각 등록할 수
있고, 전부 등록할 필요는 없습니다 - 등록 안 한 상황은 그냥 조용히
넘어갑니다.

| 상황 | 언제 나오나요 | 권장 길이 |
|---|---|---|
| 게임 시작 인사 | 게임이 시작되고 첫 턴이 시작되기 전, 한 판에 한 번 | 5초 이내 |
| 내 차례 | 자기 차례가 될 때마다 | 1~2초 |
| 승리 | 1등으로 이겼을 때 | 7초 이내 |
| 패배 | 최하위 점수로 졌을 때 | 7초 이내 |
| 야추 | 주사위 5개가 같은 눈으로 나왔을 때 | 3~4초 |
| 라지 스트레이트 | 주사위가 라지 스트레이트로 나왔을 때 | 3~4초 |
| 풀 하우스 | 주사위가 풀 하우스로 나왔을 때 | 2~3초 |
| 포 카드 | 같은 눈 4개 이상이 나왔을 때 | 2~3초 |
| 상단 보너스 | 상단 점수 합계 63점을 처음 넘겼을 때 | 3~4초 |

**"내 차례"처럼 자주 나오는 상황은 짧게 만드세요.** 4인 게임이면 한
판에 48번까지도 나올 수 있는 대사라, 길면 금방 지겨워지고 다른 대사가
밀려서 안 나올 수도 있습니다. 반대로 "게임 시작 인사"나 "승리/패배"는
한 판에 한 번뿐이라 조금 더 길어도 괜찮습니다.

- **한 상황에 여러 개를 등록하면 재생할 때마다 무작위로 하나를
  골라줍니다.** "내 차례" 같은 자주 나오는 상황에 대사를 2~3개
  준비해두면 매번 같은 말만 반복하지 않아서 좋습니다.
- **WAV보다 OGG나 MP3를 권장합니다.** 소리 자체는 똑같이 들리는데
  파일 용량이 WAV의 1/10 정도로 훨씬 작아집니다. 아래 "4. 전체 용량"
  한도를 여유 있게 지킬 수 있고, 온라인 대전에서 다른 사람에게 전달할
  때도 훨씬 빠릅니다.
- **한도: 개당 길이 7초, 파일 크기 1MB까지.** 7초가 넘는 파일은
  올라가지 않습니다 - 편집 프로그램에서 짧게 잘라서 다시 올려주세요.
  (위 표의 "권장 길이"는 7초보다 훨씬 짧은 경우가 많은데, 7초는 최후
  한도이고 실제로는 상황에 맞게 훨씬 짧게 만드는 게 좋다는 뜻입니다.)

## 4. 전체 용량

캐릭터 하나(스탠딩 이미지 + 썸네일 + 보이스 전부 합쳐서)의 총 용량
기준입니다.

- **권장: 10MB 이내**
- **15MB를 넘으면 온라인 대전에서 다른 사람에게 전달되지 않을 수
  있습니다.** 혼자 하거나 로컬(같은 화면)로 할 때는 문제없지만, 온라인
  대전을 생각한다면 15MB 밑으로 맞춰주세요.
- 용량을 줄이려면: 이미지는 WebP로, 보이스는 OGG나 MP3로 바꾸는 게
  가장 효과적입니다.

## 5. 만드는 순서

1. 게임 시작 화면에서 **[캐릭터 관리]** → **[새로 만들기]**를 누릅니다.
2. 이름을 정하고, **스탠딩 이미지**(1번)와 필요하면 **썸네일**(2번),
   **보이스**(3번)를 하나씩 올립니다.
3. **[저장]**을 누르면 끝입니다. 게임을 시작할 때 캐릭터 선택 화면에서
   방금 만든 캐릭터를 고르면 바로 쓸 수 있습니다.
